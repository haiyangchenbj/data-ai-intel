趋势

月度趋势分析

趋势一：Agent 治理从"数据层"延伸至"互操作层"，MCP 规范成为关键基础设施 ★★★（高可信）

核心判断：Databricks Unity AI Gateway GA（7/7）、Snowflake Cortex AI Gateway（7/29）与 MCP 2026-07-28 规范在同一个月内完成"产品+标准"双落地，Agent 治理的战场从单一平台内的数据访问控制扩展至跨平台互操作层的统一审计与成本管控。Snowflake 作为数据平台商首次以 MCP 网关统一治理自有及第三方 Agent，Databricks 以 Budgets GA 补齐成本控制，MCP 规范的无状态核心设计使 Agent 调用数据平台工具首次具备可规模化、可审计的工程基础。

关键事件：

日期厂商事件治理维度

补充观察：

MCP 2026-07-28 规范完成了三项关键架构升级：无状态核心（Stateless Core）消除了此前版本的状态耦合问题，统一能力发现（Streamable HTTP + JSON-RPC）使 Agent 发现和调用工具标准化，全链路追踪为每次工具调用提供完整审计链。这标志着 MCP 从实验性协议进入生产级标准。Snowflake Cortex AI Gateway 将治理边界从数据延伸到 Agent——不仅控制谁能访问什么数据，还审计 Agent 在做什么、花了多少钱、调用了哪些第三方工具。Google Cloud Agentic Data Cloud 将 borderless lakehouse 与 Knowledge Catalog 整合为单一行动系统，调研显示 83% 组织需升级基础设施支持 Agentic AI（vendor survey data）。

So what：数据平台负责人应在 Agent 治理能力中新增"跨平台互操作审计"评估维度，要求厂商提供 MCP 兼容路线图；采购方可利用 Snowflake 和 Databricks 网关同步发布窗口进行 POC 对比，重点关注延迟开销和第三方 Agent 兼容性。

趋势二：中国政府数据政策从"确权"迈入"定价"，制度框架密集落地 ★★★（高可信）

核心判断：7 月中国数据政策在三个维度完成从框架到落地的关键推进——数据产权登记制度全国落地（"三权分置"登记凭证可作为资产入表）、"词元交易"概念首次将 Token 定义为可交易数据资产、APEC 多边框架确立数据跨境治理方向。加上四部门"AI+人社"、九部门科技金融数据两个跨部委垂直方案，数据要素的制度基础设施在一个月内密集成型。

国家数据局局长刘烈宏在 7 月多次公开阐述"语义贯通"路线——以元数据和语义映射替代强制格式统一，让数据自带标准化语义。这一路线与 MCP 规范的无状态核心设计思路异曲同工——都是在互操作层面而非存储层面解决问题。APEC 圆桌会是数据跨境治理首次上升到亚太区域多边框架，刘烈宏主持、27 个经济体参与，主席声明确立三大方向，为中国数据平台厂商出海提供了制度性铺垫。"词元交易"概念将数据要素定价推进到 AI 原生计量单元，若能落地将成为全球首个将 Token 纳入数据交易体系的制度创新。

So what：数据平台负责人应将"数据产权登记兼容性"和"Token 计量的数据资产化"纳入下半年产品路线图；面向政企市场的竞品厂商建议尽快与信通院标准体系对接，数据产权登记系统接口将成为政府采购准入门槛；出海厂商应将 APEC 多边框架作为合规路线图基准。

趋势三：数据平台 AI 能力独立商业化，Agent 驱动的新收入模型成型 ★★（中可信）

核心判断：Databricks Genie 全线切换按量付费（7/7-7/9）、Snowflake Cortex AI Gateway 以网关形式统一治理和计费多平台 Agent，标志着数据平台厂商的 AI 能力从"附赠功能"正式升级为独立商业化产品线。资本端，Databricks $30 亿融资（估值 $1880 亿）明确投向多 AI 治理，Together AI $8 亿 C 轮（估值 $83 亿）验证了算力租赁新云模式的独立商业价值。但 Genie 按量付费的用户接受度和实际收入贡献数据尚未公开，判断主要基于产品定价动作。

补充观察：

Databricks CEO Ali Ghodsi 在融资报道中直言"GPU 正在耗尽"是当前的业务瓶颈而非远期规划，同时确认将托管 Kimi K3 等中国开源模型。这一表态揭示了 Agent 时代数据平台面临的结构性张力：Agent 越多→模型调用越多→GPU 需求越大→成本和供应链压力越大。Snowflake Cortex AI Gateway 作为数据平台商首次以 MCP 网关统一治理跨平台 Agent 的访问、审计与成本，其定价模型若以 Agent 调用次数或 Token 消耗计费，将开创数据平台"Agent 流量变现"模式。OceanBase 在 6 月发布湖库一体 AI 数据库后，7 月即启动成立以来首次外部融资，$14 亿年化收入 +70% 增速（vendor-reported）表明国产数据库 AI 转型正在获得资本市场估值溢价。

So what：采购方应关注数据平台 AI 能力的定价模型，按量付费的波动性可能使年度成本远超固定许可模式，建议在合同中约定成本预警和上限机制；数据平台负责人应对 Genie/CoCo/Cortex AI Gateway 等 Agent 化产品的单位经济模型做独立测算，避免"Agent 越多→账单越大"的预算失控。

趋势四：国产数据基础设施 AI 原生化从单点发布走向全栈对齐 ★★★（高可信）

核心判断：腾讯云 AI DLC（Spark+Ray 统一湖仓）、阿里云 PolarDB Lakebase（湖库一体）、星环科技 GPU 原生数据库三者在一个月内密集发布，分别从计算引擎、数据库架构和芯片层三个维度推进 AI 原生化。与 6 月火山引擎 Data Agent Pro 和 SelectDB Agent 引擎形成连续，国产数据基础设施的 AI 转型已从"个别厂商的差异化动作"变为"头部厂商的结构性对齐"，跨厂商共识强度显著。

So what：数据平台负责人建议将"是否为 Agent 原生设计"作为下半年选型的独立评估维度，重点考察 MCP 支持、自然语言驱动能力和 Token 级计费模型；采购方应关注国产厂商 GPU 原生路线的实际生产验证——星环科技预览版和阿里云 AnalyticDB V2.0 均为早期阶段，建议以 POC 为主。

趋势五：数据平台 M&A 进入"价值重估"周期，独立平台被系统性整合 ★★（中可信）

核心判断：Airtable $12.85 亿被 Bending Spoons 收购（较 2021 年峰值折价 89%）、Domo $4 亿被 Progress 收购、Cognite $31 亿被施耐德收购，三笔交易在 7 月密集出现，均以显著低于历史峰值的价格成交。独立数据/BI 平台的退出路径正在从 IPO 转向被传统基础设施或产业巨头整合，估值逻辑从"增长故事"切换为"战略能力补齐"。同时苏赛门 S1 提交和 Databricks 密集私募替代 IPO，进一步印证了公开市场对数据平台估值的不确定性。

Airtable 作为低代码数据库平台代表，ARR $4.8 亿（+20% YoY）、50 万+组织客户、80% Fortune 100 采用率，却以仅 2.7x ARR 的企业价值成交——远低于 Snowflake（~20x）和 Databricks（~27x）的估值倍数。这说明"有数据平台能力≠有数据平台估值"，真正的溢价在于 AI 工作负载黏性和多引擎生态锁定能力。Progress Software 收购 Domo 是其第三次数据平台收购，传统基础设施厂商正在通过并购系统性地构建 AI 数据栈。Bending Spoons 7 月 1 日纳斯达克上市、同月即宣布收购 Airtable，其"并购→深度转型→持续优化"的运营模式对 SaaS 数据平台形成新的退出范式。

So what：数据平台负责人应评估现有 BI/数据分析工具的供应商可持续性——独立 BI 平台被整合的趋势明确，建议优先选择有数据平台生态深度捆绑的产品；采购方应在合同中加入控制权变更条款，确保被收购后服务不中断。
