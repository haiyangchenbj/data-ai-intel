Google BigQuery 推出增强分析函数，把归因分析收编为 Agent 可调用的 SQL 原语

来源： Agent-ready analytics: Unlocking insights with BigQuery augmented analytics
摘要： BigQuery 新增 AI.KEY_DRIVERS、AI.CAUSAL_EFFECT、ML.CORRELATION、ML.DETECT_CHANGE_POINTS、ML.TREND、ML.SEASONALITY 六个增强分析表值函数（TVF），用 AI、机器学习与统计方法定位指标变化根因、量化因果影响、识别趋势与季节性；输出结构化 SQL，可封装为 Agent 的 skill 并链式调用，分析在数据所在处就地执行。
为什么对数据平台重要： 把「为什么指标变了」这类归因分析从外部 BI 与数据科学工具收编为数据平台内置、Agent 可直接调用的 SQL 原语，是「Agent-Ready 数据平台」主线的实质性落地，降低了 Agent 做自动化调查的工程门槛。

Google Dataflow 批处理暂停/恢复正式 GA，并接入 RTX PRO 6000 Blackwell GPU

来源： Announcing Pause/Resume and NVIDIA RTX PRO 6000 Blackwell GPU support in Dataflow
摘要： Dataflow 批处理作业暂停/恢复正式 GA，长跑作业失败后可从中断点续跑而非全量重跑，也可主动暂停以应对外部条件变化；同时支持 G4 VM 上的 NVIDIA RTX PRO 6000 Blackwell GPU（96GB vGPU、1.6TB/s 带宽），可在作业内直接跑 70B+ 参数模型推理，并复用 RunInference、GPU 弹性伸缩等原生能力。
为什么对数据平台重要： 暂停/恢复补齐批处理引擎的容错与成本短板，GPU 接入把大模型推理下沉进数据处理流水线，是计算引擎在「工程效率 + 推理算力」两个维度上的同步强化。

【投融资】CADDi 完成 1.14 亿美元 D 轮，制造业 AI 数据平台估值达 12 亿美元

来源： Exclusive: Manufacturing AI startup CADDi valued at $1.2 billion following $114 million Series D
核心数据： 1.14 亿美元 D 轮，估值 12 亿美元（较 2025 年 3 月的 4.7 亿美元翻倍多），累计融资 2.34 亿美元；Moore Strategic Ventures、Coreline Ventures、丰田 Woven Capital、Recruit HR Tech Fund 等 8 家参投。
摘要： CADDi 从 CAD 图纸检索（CADDi Drawer）扩展为「制造业 AI 数据平台」，整合 CAD 文件、ERP、HR 等多系统数据供人与 AI Agent 使用；新增 CADDi Agent 与 6 个工作流产品，用自研模型解析图纸、通用大模型处理文档，捕获资深工程师的隐性知识。
对数据平台的影响： 映射「数据智能 + 工程效率」维度——把制造场景多源异构数据统一结构化、供 Agent 消费，是垂直行业「AI 数据平台」的典型样本，也印证工业 Agent 数据层的机会。

【投融资】Keewano 完成 1200 万美元种子轮，推出面向 AI Agent 的事件序列数据库

来源： Startup Keewano launches agent-focused database and pulls in $12M in funding
核心数据： 1200 万美元 Seed，Hetz Ventures 领投，a16z speedrun、Remagine Ventures、DIG Ventures 参投；估值未披露。
摘要： KeewanoDB 以「实体」为主键按序存储完整事件序列，Agent 可直接在库内通过 MCP 运行分析脚本，无需 ETL 或表扁平化；公司称 2.5 亿事件半秒内查询，客户从 BigQuery/Snowflake 摄取数据声称 token 节省约 84%（厂商自述，未独立验证）。
对数据平台的影响： 映射「Agent-Ready 数据平台」维度——「数据库为 Agent 重新设计」的新兴方向，与云厂商多模态数据底座叙事同向，但性能数据未独立审计，需观察落地。

【投融资】KKR 与 Neuberger 收购医疗数据协作平台 Datavant 少数股权
