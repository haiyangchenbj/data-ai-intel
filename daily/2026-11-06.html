EDB 收购 Altinity：Postgres 与 ClickHouse 两大开源引擎团队合并

来源：EDB 官方新闻稿
摘要： EDB 于 11 月 5 日宣布收购 ClickHouse 生态头部服务商 Altinity，交易金额未披露。Altinity 团队整体并入 EDB 成为其实时分析部门，Postgres 第一大商业贡献者与 ClickHouse 第二大贡献者就此合并，双方合计服务超 1,860 家企业客户。整合路线包括在 EDB Postgres AI 平台内统一事务、实时分析与智能体负载，四季度推出集成企业版 ClickHouse 能力，并规划共享 Apache Iceberg 目录与跨引擎一致的访问控制。
为什么对数据平台重要： 事务与实时分析的引擎边界正在被并购动作打破，「一个数据层承载智能体负载」从路线图叙事变成资产整合。对采购方而言，Postgres 加 ClickHouse 组合的多模型一体化将直接影响数据库选型、开源商定支持服务的成本谈判与厂商合并评估。

Dropbox 宣布 3.5 亿美元收购 Tigris Data，同步推出 DBX Agent Cloud

来源：Dropbox 投资者关系新闻稿
摘要： Dropbox 于 11 月 5 日宣布拟以 3.5 亿美元收购全球分布式对象存储平台 Tigris Data，交易预计四季度交割，同时发布 DBX Agent Cloud——以独立 S3 兼容对象存储起步、面向构建 AI 应用与智能体的企业和开发者的存储与数据层，后续计划扩展文件系统与内容处理能力。同日发布的三季度财报显示营收 6.373 亿美元、同比增长 0.5%。
为什么对数据平台重要： 消费级存储厂商携现金流与海量用户基础反向进入 AI 对象存储市场，S3 兼容存储层的竞争者增加，意味着智能体基础设施的存储议价权趋于分散，跨云数据放置与可移植性将成为新的采购考量维度。

Databricks 打开跨生态接入面：Power BI 语义模型进 Genie，伙伴平台入策略白名单

来源：Databricks 2026 年 11 月发布说明
摘要： Databricks 11 月 5 日发布三项更新：外部知识源进入 Beta，可把 Power BI 语义模型的元数据与度量定义拉入 Databricks 供 Genie 回答时引用；上下文入口策略新增放行 Power BI、Tableau Cloud、dbt Cloud 及 Genie 的 Slack 与 Teams 应用，平台侧自动维护伙伴地址；SSH 隧道会话可运行 Claude Code 与 Codex，模型请求经 Unity Gateway 走 SSH 凭证认证。
为什么对数据平台重要： 语义定义与访问边界开始跨生态流动，微软语义层资产可直接喂养 Databricks 智能体，厂商围墙的数据面被从治理侧凿开。对多平台并存的企业，语义层归属与入口策略审计将成为架构治理的新决策点。

Snowflake Iceberg 表存储备份转正，托管 MCP 服务器支持智能体后台运行 [补录 11-04]

来源：Snowflake 发布说明
摘要： Snowflake 11 月 4 日功能更新：Snowflake Storage for Apache Iceberg 表与使用该存储的动态 Iceberg 表在 AWS 上备份能力正式 GA；托管 MCP 服务器中 CORTEX_AGENT_RUN 与 CODING_AGENT 工具新增后台运行参数，调用立即返回句柄供轮询；HTML 报告进入公开预览，可由 CoCo 与 CoWork 生成并作为制品分享。
对数据平台的影响： Iceberg 存储备份 GA 补齐开放表格式进入生产的关键运维短板，动态表与静态表统一备份降低了湖仓表的上生产门槛；MCP 服务器原生支持后台任务，说明平台开始把智能体当作一等调度对象而非一次性调用方。

AWS S3 Tables 提供数据湖现代化托管迁移路径 [补录 11-04]

来源：AWS What's New
摘要： AWS 11 月 4 日宣布 S3 Tables 为数据湖现代化提供简单低成本路径，并新增六个 API 支持把 AWS Glue Data Catalog 中的表迁移进 S3 表桶（含 StartTableMigration、SyncTableMigration 等），由服务托管迁移流程。
对数据平台的影响： 迁移工具链由厂商托管后，存量 Hive 湖表向 Iceberg 集中的摩擦显著下降，Iceberg 的集中度会进一步抬升；对多目录并存的企业，目录层的整合与收敛时点可以开始纳入架构规划。
