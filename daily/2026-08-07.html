腾讯云Agent Memory 2.0.0发布：Team Memory将Agent长期记忆从个人扩展到团队协作

来源： 腾讯云官方公众号
摘要： 腾讯云Agent Memory 2.0.0大版本8月6日正式上线，全新升级Team Memory，将长期记忆能力从个人扩展到团队协作场景。团队与Agent协作中产生的代码知识、项目文档、历史对话和工作方法，均可沉淀为四类记忆资产（Wiki、CodeGraph、ChatMemory、Skill），在不同Agent间共享并按角色和任务装配。同步上线的Memory Hub控制台提供记忆的创建、审核、授权、分享和版本的统一管理。该项目开源80天GitHub Star突破15,000，多次登顶GitHub Trending日榜。
为什么对数据平台重要： Agent记忆从"会话内缓存"升级为"跨Agent可治理的持久化基础设施"，直接触及数据平台在Agent时代的核心命题——Agent需要的不只是数据访问，而是可继承、可审计、可按需装配的上下文资产。Team Memory引入的四类记忆资产（Wiki/CodeGraph/ChatMemory/Skill）和按角色装配机制，在工程层面定义了"Agent就绪的数据基础设施"应具备的记忆治理能力。Memory Hub的权限和版本管理进一步将记忆纳入企业治理框架。

Snowflake Native Apps支持Cortex Agents与MCP服务GA，实现跨应用Agent互操作

来源： Snowflake Release Notes
摘要： Snowflake Native Apps中Cortex Agents和MCP服务器功能正式GA。应用开发者可在App的setup脚本中创建Cortex Agent（提供对话式体验）、Snowflake托管的MCP服务器（将Cortex Search、语义视图、存储过程和UDF暴露为MCP工具）以及SPCS托管的MCP服务器。关键新能力是inter-app communication——一个App的Agent可直接调用另一个App的Agent或MCP服务器，各App保持数据和逻辑私有，Agent仅通过暴露的工具跨App通信。消费者通过caller grants和feature policies控制App创建的Agent和MCP服务器。
为什么对数据平台重要： 这是数据平台应用生态首次原生支持Agent间互操作。Snowflake从"数据市场"向"Agent市场"的演进由此获得关键基础设施——App不再是独立的数据产品，而是可通过Agent互相编排的功能单元。Inter-app agent communication机制在安全模型上做了精细化设计（每App数据私有+工具暴露+消费者审批），为数据平台上的多Agent协作提供了治理模板。与Databricks Unity AI Gateway从网关层治理Agent不同，Snowflake选择在Native App层嵌入Agent能力，两条路线将在Agent生态治理上形成对位。

Databricks Genie One进驻Google Sheets与Microsoft Excel

来源： Databricks Docs August 2026 Release Notes
摘要： Genie One现已集成至Databricks Connector for Google Sheets和Excel Add-in中。用户在Google Sheets侧边栏和Excel中可直接用自然语言查询Databricks中的受治理数据，将查询结果以原生行列格式导入电子表格。Genie仅回答用户有权访问的数据，治理由Unity Catalog统一执行。Excel Add-in还支持write-back，允许有权限的用户将Excel更新推送回Databricks。
对数据平台的影响： Genie One从Databricks自有界面进入全球最广泛使用的两大办公工具，意味着自然语言数据查询正在从"数据平台内的差异化功能"变为"办公工具中的标配能力"。Excel write-back进一步闭合了分析到行动的循环，使数据平台的治理边界从数据库延伸到终端用户的电子表格操作。这是BI能力"去工具化"的标志性一步——查询和分析不再需要独立BI界面。
