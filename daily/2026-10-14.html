🔥 今日最重要的3个变化

  1. 非结构化数据的语义处理正从外挂脚本变成数仓原生函数
  2. 数据权限的治理边界正从表级下探到行级与字段级
  3. 开放表格式的并发写瓶颈开始由引擎侧承担消化
总判断：数据平台的竞争焦点正从功能覆盖转向智能体能否安全、可审计地调用数据。当天三件事分别落在语义计算原生化、权限颗粒度收紧、开放表并发冲突的引擎侧消化上，共同指向同一条路径：让智能体拿到的上下文可算、可授权、可并发写入。

Google Cloud 把自然语言驱动的语义聚合做成仓库内原生函数

来源： BigQuery 发行说明
摘要： Google Cloud 在 BigQuery 发行说明中确认，`AI.AGG` 函数正式可用，可按自然语言指令对非结构化输入数据做语义聚合；同日生成式 AI 函数新增对 gemini-4-argon 模型的支持。
为什么对数据平台重要： 过去要在数仓之外拼一套检索加模型调用才能完成的"按语义归并"，现在成为 SQL 层的聚合算子。语义计算下沉进引擎后，非结构化数据不必先转成结构化字段再分析，数据平台在向量检索之外多承担一类语义计算职责，外挂式语义处理工具的空间相应收窄。

AWS 为简化版行级安全提供新接口，权限治理继续下沉

来源： AWS SDK for Go v2 发版说明
摘要： AWS 在当日发布的 SDK 变更说明中为 Lake Formation 增加一批新接口与配套文档，用于简化版行级安全（Simple Row-level Security）。
为什么对数据平台重要： 行级安全长期需要按表逐条拼接策略并绑定身份，配置成本高、易漂移。收敛成托管接口后，行过滤具备与列级掩码接近的可运维性，权限颗粒度从"表"下探到"行"，敏感数据在授权链条上被整体开放的空间随之缩小。

Redshift 自动消解 Iceberg 表的并发写冲突

来源： AWS Big Data Blog
摘要： AWS 大数据博客说明，Amazon Redshift 现在会自动解决对 Apache Iceberg 表的多数并发写入：当写入操作实际不重叠时，引擎按操作、分区与文件三个层级做 rebase 后直接提交，此前这类事务会失败并要求重试。
为什么对数据平台重要： 开放表格式的卖点是多引擎、多写入者共享一份数据，但并发提交冲突是实际落地时最常撞上的工程墙。把非重叠写入的 rebase 放进引擎，等于把湖仓的并发正确性从"应用自己重试"转成"平台保证"，多写者架构的采用门槛随之下降。

Product & Tech

Databricks 流处理支持运行中调整 shuffle 分区

来源： Databricks 产品发行说明
摘要： Databricks 产品发行说明显示，按需状态重分区（On-demand state repartitioning）正式可用，可在不丢弃检查点状态的前提下，调整有状态 Structured Streaming 查询或 Lakeflow 管道的 shuffle 分区数。
对数据平台的影响： 有状态流任务的并行度过去绑定在作业定义里，扩缩容意味着重启并重放状态。允许运行期改分区数，等于把并行度从部署参数变成运维动作，流处理作业的调优窗口被打开。

AWS Glue 零 ETL 集成可为 S3 Tables 指定自定义命名空间

来源： AWS SDK for JavaScript v3 发版说明
摘要： AWS 在当日 SDK 变更说明中列出 Glue 的新能力：在 Glue 零 ETL 集成中为 S3 Tables 添加自定义命名空间。
对数据平台的影响： 零 ETL 此前按平台默认规则为复制来的表落位命名，容易与既有目录结构冲突。允许自定义命名空间后，自动复制产生的资产可以沿用企业原有命名约定，目录治理不会被"自动化的便利"反向侵蚀。

DataSync 增强模式扩展文件系统与元数据支持

来源： AWS What's New
摘要： AWS 宣布 DataSync 增强模式新增对 FSx for OpenZFS、NFS 4.2 的支持，并增加对象元数据控制能力。
对数据平台的影响： 迁移与持续同步是数据平台落地的第一道工序，元数据能否原样保留，决定迁移后是否需要重建目录与权限。把元数据控制纳入同步能力，减少的是迁移后的返工量，而不是迁移本身的耗时。

Snowflake 细化敏感数据分类的失败信息

来源： Snowflake 发行说明
摘要： Snowflake 发行说明显示，敏感数据分类的自动分类失败时给出更具体的错误信息，DATA_CLASSIFICATION_LATEST 视图开始报告一组已定义的 ERROR_MESSAGE 值，并在可用时附带来源错误码。
对数据平台的影响： 分类覆盖率是数据治理的入门指标，但"失败原因不明"会让治理团队把时间花在排查而不是修复上。错误码结构化之后，分类失败可以接入监控与告警链路——治理动作成立的前提是它可被观测。
