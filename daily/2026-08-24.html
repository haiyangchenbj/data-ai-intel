AWS Glue 6.0 全面可用：降价 30% 并完整支持 Apache Iceberg v3

来源：AWS News Blog
摘要： AWS 8 月 21 日宣布 AWS Glue 6.0 全面可用，较此前版本降价 30%，运行时升级至 Apache Spark 4.1、Python 3.13、Scala 2.13。新版本完整落地 Apache Iceberg v3 规范（基于 Iceberg 1.11.0），包括 VARIANT 类型及其 shredding、deletion vectors、geometry/geography 空间类型、纳秒级时间戳与 unknown 类型处理；同时引入 Spark Declarative Pipelines、Arrow 原生 Python UDF、以及毫秒级实时流模式。
为什么对数据平台重要： 这是主流云厂商首次在无服务器托管 Spark 服务上完整落地 Iceberg v3，开放表格式从"可选能力"走向"默认底座"；VARIANT 的 shredding 消除半结构化数据的重复副本与解析代码，配合 30% 降价直接压低湖仓 ETL 的单位成本，加速企业从专有格式向开放表格式迁移。

OpenAI 收购实时数据库 InstantDB 团队，智能体状态管理成基础设施

来源：RuntimeWire
摘要： InstantDB 创始人 8 月 22 日宣布团队整体加入 OpenAI，并入开发者工具与 Agent 工作流团队（含 Codex）。InstantDB 是实时数据库与后端即服务平台，累计服务超 1.7 万用户、支撑 40 万应用、处理约 25 亿笔交易。Instant Cloud 将停止新注册并于 2027 年 8 月 31 日关停，开源代码库保留自托管。交易未披露财务条款，属人才型收购。
为什么对数据平台重要： AI 巨头直接收购实时数据库团队，印证"Agent 需要持久状态管理"——跨多步操作的智能体必须实时读写、处理并发与冲突解决，实时数据库/同步引擎因此从应用后端组件上升为 Agent 基础设施的关键控制层。数据库工程能力正加速向 AI 平台收敛。

AWS 发布 ADOP 参考架构，AI 代理驱动数据工程全流程自动化

来源：AWS Machine Learning Blog
摘要： AWS 发布 Agentic Data Operations Platform（ADOP）参考架构，基于 Amazon Bedrock 与自选 AI 编码工具，由数据接入代理派生元数据、本体、质量、ETL、编排等专用子代理，自动化完成 Bronze 到 Silver 到 Gold 的完整生命周期。ADOP 定位为"构建期加速器而非运行时依赖"：代理在开发环境生成确定性产物（PySpark、SQL、Airflow DAG、IAM/Cedar 策略），经 CI/CD 推送生产，默认生产环境不再调用模型。
对数据平台的影响： 数据工程的价值从"写管道"转向"审产物"，合规从下游关卡变为上线时的内联控制；其"架构契约而非模型"的设计，用统一蓝图约束 Claude Code、Cursor、Codex 等编码工具的一致性，为数据工程团队交付数据产品提供了可复用的工程范式。

Databricks Unity Catalog 引入上下文属性，代理数据访问治理进入 Beta

来源：eCorpIT
摘要： Databricks 8 月 21 日在 Unity Catalog 的属性访问控制（ABAC）中引入 context attributes Beta，新增 `request.is_on_behalf_of` 与 `request.client_id` 两个上下文属性，策略可针对"代理代用户发起"的请求做列掩码或行过滤——同一用户在直接查询时可见全部数据，通过 OAuth 应用代其访问时则被掩码。
对数据平台的影响： 数据治理的控制粒度从"用户身份"下沉到"代理身份"，代理数据访问治理成为数据平台安全的新维度。但该能力存在三个覆盖缺口——个人访问令牌不设置该属性、Genie 被显式排除、内置 CLI 客户端共享同一 client_id，代理治理的实际边界取决于令牌治理是否先行闭合。

【降级】Google Cloud AlloyDB ScaNN 四级树索引，向量检索扩展至百亿

来源：Google Cloud Blog（转载）
为什么值得继续看： AlloyDB 的 ScaNN 向量索引引入四级树结构（预览），检索复杂度从三级树的 O(N^1/3) 降至 O(N^1/4)，官方称可支撑超 100 亿向量，内部测试 p95 延迟 ≤51 毫秒、召回率 95%。该发布约在 8 月 20 日（略早于本窗口起点 8/21 08:00），故降级收录。
需要等待什么信号确认： 四级树索引的正式 GA 时间，以及在真实工作负载下召回-延迟-成本三角是否复现官方基准；云数据库内嵌向量检索向百亿规模扩展，将影响独立向量数据库与 RAG 容量规划的选型判断。
