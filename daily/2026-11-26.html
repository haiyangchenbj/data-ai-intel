Snowflake Native Apps 对含容器应用提供 FedRAMP 支持（Azure）正式可用

来源： Snowflake Release Notes
摘要： Snowflake 11 月 25 日功能更新：Native Apps 框架在 Azure 上对包含容器的应用提供 FedRAMP 支持，正式可用。此前容器类 Native App 无法进入 FedRAMP 认证环境，美国联邦客户只能在「用容器能力」与「留在合规区」之间二选一。
为什么对数据平台重要： 受监管市场的合规边界直接决定应用生态上限。容器应用纳入 FedRAMP 后，软件商可以向联邦客户交付带自研运行时的数据应用，Snowflake 的应用分发半径从商业市场扩展到政府市场，合规能力本身变成应用分发的准入前提。

Azure Databricks Lakeflow 作业级查询性能洞察默认开启

来源： Azure Databricks Release Notes
摘要： 自 2026 年 11 月 25 日起，启用合规安全配置文件的合格工作区默认获得改进的 Lakeflow 性能可观测性：作业层面直接展示任务级查询性能指标与数据量指标，并提供一键优化入口，覆盖无服务器计算、SQL 仓库与 Lakeflow 管道。
对数据平台的影响： 性能可观测性从「可选开关」变成「默认能力」，管道调优的人力门槛进一步下降；对治理敏感行业客户，作业级性能与数据量基线可以直接纳入成本审计视角。

BigQuery 迁移服务新增 Databricks SQL 与 Spark SQL 方言转换（预览）

来源： BigQuery Release Notes
摘要： 11 月 24 日，BigQuery Migration Service 进入预览：支持将 Databricks SQL 与 Apache Spark SQL 3.x/4.x 转换为 GoogleSQL，并直接从 Databricks 提取 schema 元数据，为存量作业整体搬迁提供托管工具链。
对数据平台的影响： 迁移工具是最便宜的获客武器：把「换引擎」的第一道门槛——方言改写与元数据搬迁——做进托管服务后，BigQuery 直接面向 Databricks 存量 workload，跨平台切换成本被系统性压低。[补录 11-24]
