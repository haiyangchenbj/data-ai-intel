Databricks 上线 AI Index：以一万家企业真实用量公开模型采用与成本数据

来源： Databricks 官方博客
摘要： Databricks 于 11 月 16 日上线 Databricks AI Index，将 Unity Gateway 上超过 1 万家企业的匿名聚合用量数据（模型 token 份额、支出份额、周度支出模式）与编码 Agent 基准（任务成功率、每任务成本）合并为每周更新的公开资源。官方披露的关键变化：依赖单一模型供应商的企业占比从 7 月的 64% 降至 11 月初的 28%；开放权重模型 token 份额从 7.3% 升至 30.9%。
为什么对数据平台重要： 治理平面（模型网关）正在成为企业 AI 用量的观测点与定价参照系；采购逻辑从 token 单价转向每任务成本，平台厂商掌握真实账本即掌握选型话语权，数据平台与模型采购决策进一步绑定。

Snowflake 双双 GA：Cortex AI Function Studio 与 AI Function Optimization 同日转正

来源： Snowflake 发布说明
摘要： Snowflake 于 11 月 16 日将 Cortex AI Function Studio 与 AI Function Optimization 同时转为 GA。前者支持以自然语言（Cortex Code CLI 或 Snowsight AI Studio）创建面向文本、文档、图像、音视频的 AI 函数，自动完成提示词、模型选择与工作流策略的基准测试；后者通过 AI_FUNCTION_OPTIMIZATION 实验类型，在同一数据集与指标下评估多模型候选的质量与估算成本，并将选中结果物化为带稳定 SQL 接口的受治理可复用函数，原函数不被修改。
为什么对数据平台重要： AI 函数从「能调用」走向「可自动调优」，成本与质量在同一 SQL 接口内可量化权衡；调优产物直接物化为受治理资产，把模型选型、成本控制与数据治理收敛进仓库原生能力，同维度能力已成为各大平台竞争焦点。

微软发布 M365 全球故障初步事后报告：三重因素叠加引发级联失效

来源： 凤凰网科技报道
摘要： 微软于 11 月 16 日发布上周 Microsoft 365 全球故障的初步事后报告（Preliminary Post-Incident Report），并经高管 Charles Lamanna 公开说明：7 月部署的网关软件修复引入锁竞争缺陷，叠加 Teams 流量切换增加主网关负载、另有约 14% 服务器容量因前一日的无关问题不可用，自动流量调度反而放大压力，形成级联故障，峰值时超过 80% 网络网关服务器失去响应。Exchange Online 受影响最重，Fabric、Power BI、Purview 等依赖邮件链路的功能受到不同程度波及。完整技术报告承诺本周晚些时候发布。
为什么对数据平台重要： 本期窗口内的治理与 BI 平台（Fabric/Power BI/Purview）随邮件链路一起受波及，印证数据平台可用性已与大平台底层基础设施强耦合；网关级共享依赖使局部缺陷演变为全球级联失效，跨区容灾与恢复目标设计需要按最坏情况重新校验。

腾讯云发布首个数据库 Agent 平台 TencentDB Agent

来源： 腾讯云数据库（腾讯新闻同步）
摘要： 腾讯云 11 月 16 日公布首个数据库 Agent 平台 TencentDB Agent，定位生产环境自主诊断与结论交付，而非问答助手。核心架构为 Safety、Skill、Memory 三支柱：操作权限分四级（只读自动执行、变更二次确认、高危永久拒绝），VPC 内部署、权限与 CAM 一比一对齐、全链路留痕；沉淀约十万级工单经验，封装 1600 多个 OpenAPI，覆盖 MySQL、Redis、MongoDB 等 14 款数据库；实例级到客户级三层记忆，官方称场景匹配准确率从 48% 提升至 76%（腾讯披露口径）。
对数据平台的影响： 国内云厂商首次把数据库运维 Agent 平台化，把 DBA 诊断经验封装为可组合能力，运维工程效率维度出现新竞争位；分级防护加全链路审计的方案，也给出了 AI 代理接入生产数据库的治理参照。

Looker 秋季更新集中转正：Dashboard Agents、Managed MCP Server、语义层索引入 Knowledge Catalog

来源： Looker 官方秋季通讯（Google 开发者论坛）
摘要： Google 于 11 月 16 日发布 Looker 秋季更新通讯，多项能力集中 GA：嵌入用户自定义与 LookML 仪表板的 Dashboard Agents；Managed MCP Server——外部 AI Agent 可经 MCP 安全发现并查询受治理语义层；LookML 自动索引进 Knowledge Catalog，将 Looker 语义模型纳入统一目录；对话式分析的 Token 用量观测（System Activity 仪表板）同步 GA，Data Apps 进入 Preview。
对数据平台的影响： 语义层正成为 Agent 接入企业数据的受治理入口——MCP 服务化让外部 Agent 在权限与语义约束内查询指标；语义模型沉淀进目录则把「目录即治理」从表结构扩展到业务定义，治理边界随之从数据面覆盖到 AI 面的入口。
