腾讯云发布 AI 数据底座 TDSQL Nexa，数据库全面面向 Agent 重构

来源：雷峰网
摘要： 8 月 20 日，在 2026 DTCC 中国数据库技术大会上，腾讯云正式发布面向 AI 时代的数据底座 TDSQL Nexa，将事务处理、全文及向量检索、AI 计算、大规模分析统一到一个数据平台，并通过 Nexa Knowledge 沉淀业务语义，为每个 Agent 配置独立身份与行列级权限。腾讯云测试显示，在可观测场景中相比开源组合方案计算性能提升 10 倍以上、成本降低 60% 以上；结合业务语义后 Agent 生成的 SQL 基本无需人工修改。
为什么对数据平台重要： 这是国内云厂商首次以「Agent 数据底座」为定位发布完整数据库产品，将多模统一承载、Agent 原生架构、语义与记忆、治理与自治四类能力产品化。腾讯云同期披露 TDSQL-C 已服务 50 万开发者、Agent Memory 开源 80 天获 2 万 GitHub Stars、DatabaseClaw 现网故障 3 分钟定位，标志着数据库服务对象从人转向 Agent 由叙事进入生产落地，为国内厂商的 Agentic Database 竞速确立了产品化样板。

Cloudera 联合 NVIDIA 为 Spark 4.1 引入原生 GPU 加速，数据工程走向异构算力

来源：Cloudera
摘要： 8 月 20 日，Cloudera 在 EVOLVE Singapore 上宣布，在 Cloudera Data Engineering 中为 Apache Spark 4.1 引入由 NVIDIA CUDA-X 库 cuDF 驱动的原生 GPU 加速，用户无需改写 PySpark 或 SQL 代码即可获得最高 4 倍的工作负载加速，同时降低云基础设施成本，可跨公有云、私有云、主权云和本地环境一致部署。
为什么对数据平台重要： 数据准备速度正成为 AI 落地的前置瓶颈，Cloudera 调研显示 84% 受访者称 AI 工作负载推高了基础设施成本。将 GPU 加速内嵌到 Spark 引擎并以零代码方式交付，意味着数据工程从 CPU 通用算力向 GPU 异构算力的迁移不再需要重写作业，把性能提升的决策门槛降到最低，也把数据就绪速度重新拉回数据平台竞争的前沿。

AWS Redshift 系统表接入 S3 Tables，突破 7 天保留限制

来源：AWS Big Data Blog
摘要： Amazon Redshift 系统表集成 Amazon S3 Tables，自动将系统表日志以 Apache Iceberg 格式投递到 S3 Tables，突破原有的 7 天保留限制，支持自定义保留周期，可被 Redshift、Athena、Glue、EMR 等 Iceberg 兼容引擎直接查询。
对数据平台的影响： 把数据仓库的可观测性数据开放为 Iceberg 格式并长期保留，既降低合规审计与跨仓性能分析的工程成本，也顺应了日志数据开放化的趋势——运维数据不再锁在专有系统表内，而是成为可被任意开放引擎消费的数据资产。

EDB WarehousePG 灾难恢复 GA，数仓恢复从数天压缩到分钟级

来源：PR Newswire
摘要： EnterpriseDB 宣布其 Postgres AI for WarehousePG 的灾难恢复能力 GA，为 petabyte 级分析数仓提供跨基础设施边界的容灾恢复。某银行部署案例中，恢复点回放平均从近两天缩短到 16 分钟（约 180 倍加速），全量备份从 44 小时降至约 11 小时。
对数据平台的影响： 当 AI 智能体、分析师和业务团队依赖实时分析数据做决策，数仓宕机的恢复时间从「天」级压缩到「分钟」级，直接把容灾从最佳实践变成可测试、可衡量的能力。其基于开源 Barman 与 WAL 的实现延续了 Postgres 团队熟悉的运维栈，降低主权/混合环境自建容灾的专有技术锁定。

MongoDB Atlas 支持 FOCUS v1.3 成本报告，FinOps 数据标准化

来源：MongoDB
摘要： MongoDB Atlas 现以 FinOps 开放成本与使用规范（FOCUS）v1.3 格式交付成本和使用数据，提供含货币、折扣、账户/项目映射、SKU 类别等属性的标准化账单数据集，可通过 Atlas Admin API 或账单 UI 获取。
对数据平台的影响： 跨多云和 SaaS 厂商的成本分析长期受制于各不相同的账单格式，FOCUS v1.3 的落地让 Atlas 账单无需自定义 SKU 映射即可接入统一 FinOps 管线。这是成本治理标准化的具体进展，也反映数据平台厂商开始把「可被统一成本平台消费」作为账单数据的默认能力。
