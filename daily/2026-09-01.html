AWS 官宣收购 DuckDB 开发公司 DuckLabs，开源项目保持独立基金会治理

来源： AWS 官方博客
摘要： AWS 在 8 月 31 日官方周报中确认已签署最终协议收购 DuckDB 背后的阿姆斯特丹公司 DuckLabs，协议于 8 月 26 日签署，预计 9 月初完成交割。DuckDB、DuckLake、Quack 等开源项目继续由独立的 DuckDB 基金会治理并保持 MIT 许可，创始人 Hannes Mühleisen 与 Mark Raasveldt 留在阿姆斯特丹继续主导技术方向，AWS 同时配发副总裁 Andy Warfield 的署名文章阐述"分析物理学改变"的底层判断。
为什么对数据平台重要： DuckDB 是嵌入式分析与 Agent 交互式探查场景的事实标准引擎，AWS 明确计划将其速度与 S3、Redshift、Athena、EMR、Glue、SageMaker 等服务结合。收购对象是团队而非代码，这意味着 lakehouse 竞争的焦点从表格式扩展到"谁雇佣核心引擎开发团队"，开源治理与技术路线中立性将成为所有依赖 DuckDB 的厂商（包括 Snowflake、Databricks 生态）必须重新评估的风险项。

腾讯云 TCHouse 发布 AI Function，AI 算子直接进入数仓 SQL

来源： 腾讯云开发者社区
摘要： 腾讯云 TCHouse 正式发布 AI Function，将情感分析、内容生成、结构化拆解等 AI 算子内置进数仓 SQL 引擎，像调用普通函数一样在 SQL 中直接使用大模型能力，数据不出仓即可完成文本语义处理，官方称 Token 成本最高可降 99.8%。典型场景覆盖短剧内容工业化生产、电商客诉、内容风控、金融研报与法律合同等海量文本分析。
为什么对数据平台重要： 这条路线把模型调用从"导出数据、外部脚本、结果回灌"的长链路压缩为数仓内的一行 SQL，重新定义了非结构化数据在数仓内的处理成本结构。AI 算子按 Token 计费并入平台账单，意味着数仓开始对语义处理能力直接定价，数据平台与模型服务的边界在产品层面被打通，同类能力将成为云数仓的标配竞争项。

阿里云 OpenSearch Agentic Search 2.0 正式商业化，智能体检索转向按量计费

来源： 阿里云官方公告
摘要： 8 月 31 日零点起，阿里云 OpenSearch 的 Agentic Search 2.0 搜索智能体正式退出公测转入商业化运营，按实际 Token 消耗以量计费。已开通公测的服务不会自动延续，用户需在控制台重新启用服务，官方要求业务提前规划避免线上受影响。
为什么对数据平台重要： 智能体检索从免费公测转为按 Token 计费，是 Agent 时代检索基础设施商业化的标志性节点：面向智能体的数据检索被明确定价为独立收入项，而非搜索产品的附属功能。采购方需要把智能体检索的 Token 消耗纳入数据平台成本模型，检索厂商之间的竞争也将从功能对比转向单位成本的比拼。

Databricks 详解 Lakebase Postgres 双向自动扩缩容架构

来源： Databricks 官方博客
摘要： Databricks 工程博客详解 Lakebase Postgres 的自动扩缩容实现：由于存储解耦并独立持久化在对象存储上，计算层可在不中断连接的情况下随负载双向伸缩，系统在 100 毫秒、5 秒、20 秒三个时间尺度上分别追踪内存、CPU 与工作集估计，生产数据库每月可完成超过 3.2 万次规格调整，目标是停止为用不到的峰值容量付费。
为什么对数据平台重要： Lakebase 代表湖仓平台向事务型工作负载延伸的方向，双向实时伸缩把"按峰值预留"的数据库成本模型改为"跟随负载"模型，直接改变 Agent 大量创建短生命周期数据库场景下的单位经济。三层时间尺度的控制回路设计对自建数据库平台也有工程参考价值。

华为云数博会发布系列化数据智能生态解决方案，联合伙伴覆盖治理到 Agent 开发

来源： 中国经济新闻网
摘要： 华为云在数博会期间的数据智能生态沙龙上，与滴普科技、蓝凌、软通动力、数新智能联合发布四项数据智能生态解决方案，覆盖数据智能平台、智能知识管理、数据中台与治理、多云大数据管理，延伸至数据 Agent 智能应用开发全链路。同场安永提出 AI 时代数据治理正经历从结构化到多模态、静态规则到动态智能、事后处理到实时治理的三个范式转变。
为什么对数据平台重要： 头部云厂商把数据领域上层应用开放给伙伴共建，配合"企业约八成精力投入数据准备"的判断，数据准备与治理环节正在成为生态分工的新利润池。多云管理方案宣称可降低跨境企业五云治理成本四成，治理与数据准备的智能化外包将成为平台选型的新评估维度。

国家数据局推出四项新举措：数据标注试点、词元商业模式、央国企数据开放

来源： 北京市东城区人民政府转载
核心观点： 国家数据局宣布系列新举措加快数据产业发展：在 32 个城市启动新一批数据标注先行先试；探索适配产业实际的词元商业模式；14 家央国企开放超 60 亿条高价值数据；完善数据要素相关学科专业布局。数博会发布的《中国数据产业发展报告（2026）》显示 2025 年产业规模达 6.78 万亿元，与 AI 高度相关的数据产品和服务占总产值七成以上。
