阿里云 PolarDB 推出 Agentic Database 形态，服务主体从人转向智能体

来源： 阿里云官方文档：什么是 PolarDB PostgreSQL Agentic Database
摘要： PolarDB 推出面向海量 AI Agent 场景的 Agentic Database 新形态（公测），具备秒级拉起、秒级 Branch、Scale to Zero 弹性、基于 OSS 的低成本存储与面向 MCP 的 Agent Native 访问，服务主体从「人」转向「智能体」。阿里云同期在 8 月 15 日「Agentic DB Day」系统阐述 Agentic DB 三层架构：入口层 AIDBS 以自然语言调起数据库的使用、管理与开发；数据能力层 RDS ContextDB 沉淀业务知识资产、Tair 语义缓存按语义匹配历史提问直接返回；底座层 PolarDB LakeBase 提供可持久化工作空间、AnalyticDB AgenticLake 支撑全模态数据实时分析。
为什么对数据平台重要： 阿里云把「数据库服务智能体」从单点能力打包为「入口—数据能力—底座」的成体系架构，明确数据库工作负载从确定性 SQL 扩展到多步推理与多智能体协作。这标志着国内头部云厂商的 Agentic DB 战略从概念进入分层产品化落地，竞争焦点从存储/计算性能转向智能体上下文、记忆与可审计执行。

ClickHouse 将 ClickStack 可观测性资源纳入 Terraform Provider 管理

来源： ClickHouse Blog: Announcing support for ClickStack in the ClickHouse Terraform provider
摘要： ClickHouse 官方 Terraform provider 自 v3.25 起（beta）支持 ClickStack 资源，覆盖自托管与 ClickHouse Cloud 两种部署形态。仪表盘、告警、数据源、保存的搜索、连接与 Webhook 等可观测性资源可纳入版本控制，走 terraform plan/apply 工作流。
对数据平台的影响： 把可观测性配置纳入 IaC，意味着数据平台的可观测性基础设施从「UI 手工配置」走向「代码化、可评审、可回滚」，降低 staging/生产等多环境配置漂移，映射到工程效率维度。

云器 Lakehouse 完成全球 8 朵云与 3 种 CPU 架构适配

来源： 云器科技（掘金官方账号）
摘要： 云器 Lakehouse 完成国内外 8 朵主流云平台适配（国内阿里云、腾讯云、火山引擎、华为云、百度智能云；海外 AWS、Google Cloud、Microsoft Azure），并兼容 Intel、AMD、ARM 三种 CPU 架构。企业可按业务选择云，无需为使用数据平台迁就基础设施。
对数据平台的影响： 中小湖仓厂商以「增量计算 + Single-Engine」架构实现多云与多芯片适配，降低企业数据平台对单一云厂商的绑定，映射到采购与市场格局维度，也代表国产湖仓出海的工程能力补课。
