Databricks 开放 Genie ZeroOps 公共 Beta：自治管道运维智能体走向全面可用

来源： Databricks 官方博客
摘要： Databricks 于 11 月 19 日宣布 Genie ZeroOps 进入公共 Beta，任意工作区管理员可在 Previews 页开启。该后台智能体持续监控作业、管道与表，既抓硬故障也抓「表停止更新、行数骤减」类静默异常，收集日志、源码、元数据与 Unity Catalog 血缘定位根因，在沙箱内用单元测试与试运行验证修复方案，最终以一键 PR 交付。私有预览覆盖数百家公司、观测超 8 万起真实故障，过半问题需组织特定知识才能定级处理。
为什么对数据平台重要： 数据工程的主要成本正从「建管道」转向「养管道」，ZeroOps 把定级、根因调查、修复验证整段自动化，且直接运行在 Unity Catalog 血缘与权限体系内。运维智能体从外挂脚本变成平台内建能力，将改写数据团队的人力结构，也会成为平台选型的新评估项。

阿里云财报：外部收入增速 64% 创近六年新高，AI 收入连续 13 个季度三位数增长

来源： 上海证券报·中国证券网（财报披露口径）
摘要： 阿里巴巴 11 月 19 日晚发布 2027 财年 Q2（截至 2026-09-30）财报：AI 云与算力服务收入 609.73 亿元，同比 +53%；外部客户收入同比 +64%（上季 45%，近六年新高）；外部经常性收入 +67%；经调整 EBITA 88.38 亿元，同比 +121%，利润率 14.5%；AI 相关产品收入 179.18 亿元，连续 13 个季度三位数增长；集团资本开支 504.77 亿元，同比 +60%。
为什么对数据平台重要： 增速较上季显著加快且由外部客户驱动，AI 需求已进入报表主变量；CEO 吴泳铭重申 2030 自然年云外部收入 1000 亿美元、利润率超 20% 的目标不变，真武 V900 芯片 2027 年一季度量产。
为什么对数据平台重要： capex 同比 +60% 说明供给与需求同步扩张，国内数据平台与算力采购向头部集中的势能进一步加强，同梯队厂商的定价、产能与补贴策略都将承压。

Snowflake 中旬功能批次集中转正：Cortex Agent SDK 进入 GA

来源： Snowflake 官方 Release Notes
摘要： Snowflake 于 11 月 18 日集中转正多项能力：Cortex Agent SDK 1.0.0 正式可用（Python/TypeScript，支持流式响应、会话维持与长任务重连）；Retrieve Cortex Search GA，可在 SQL 中以表函数低延迟调用搜索；Spark Monitoring UI GA；加载 Parquet/JSON/Avro/ORC 时结构化 OBJECT/ARRAY/MAP 类型的 schema 检测与演进 GA；AI_COMPLETE 提示词缓存 GA。11 月 19 日再推出 App Runtime serverless 计算与 Workspaces 开发预览。
对数据平台的影响： Agent SDK 转正意味着 agent 运行时被正式纳入平台能力边界，企业可在受治理数据之上构建 agent 而不必依赖框架自拼装；结构化类型 schema 演进 GA 与提示词缓存直接降低半结构化管道与 AI 调用的维护和成本。

BigQuery 更新：Data Engineering Agent 可观测性 GA、AI 索引开放预览

来源： BigQuery Release Notes
摘要： Google Cloud 于 11 月 19 日更新 BigQuery：Data Engineering Agent 的 agent 观测能力 GA，可在 Cloud Monitoring 监控 token 消耗、请求量与模型延迟，在 Cloud Trace 查看执行轨迹与工具调用；新增 CREATE AI INDEX 语句与 AI.SEARCH 函数（Preview），无需自管 embedding 即可对表列做自然语言检索；BigQuery Migration Service 新增迁移校验服务（Preview），可比对源仓与目标表的 schema、聚合指标与行级数据。同日披露 Dataform、BigQuery Studio 与 Colab Enterprise 的路径穿越漏洞（GCP-2026-084 安全公告）。
对数据平台的影响： agent 大量进入数据管道后，token 成本与执行审计成为治理新科目，观测能力 GA 说明平台方开始把 agent 当作一等计费与审计主体；AI 索引把语义检索下沉为表级基建，检索类工作负载的架构选择空间进一步收窄。

PostgreSQL 19 正式发布，EDB 同日宣布平台同步支持

来源： PostgreSQL 官方新闻
摘要： PostgreSQL 19 于 11 月 19 日按计划正式 GA（10 月 15 日 RC1、11 月 12 日 RC2 之后）。版本包含查询优化器改进、逻辑复制增强与多项默认值变更（JIT 默认关闭、TOAST 默认改用 LZ4 等），升级需走 pg_upgrade 或逻辑复制路径。EDB 同日宣布其 Postgres AI 平台同步提供 PG 19 支持。
对数据平台的影响： PostgreSQL 是托管数据库与湖仓连接器的事实底座，19 的默认值与兼容性变更将传导至各大云托管 PG 服务和 CDC 工具链的适配节奏，升级窗口规划需要提前纳入变更清单。
