Snowflake Expedition 2026：业务本体、智能体治理与 Oracle 云第一方合作三线齐发

来源： Snowflake 投资者关系新闻稿
摘要： Snowflake 在 Expedition 2026 虚拟大会上发布 Business Ontology（隶属 Horizon Catalog，私密预览），让企业把业务术语的官方定义集中登记，只向智能体返回经业务方批准的口径，配合 CoCo、CoWork 两个智能体使用；Cortex AI Gateway 在上月转正基础上扩展滥用检测、可观测追踪、沙箱、成本治理、动态模型路由及 Natoma 并购技术集成；CoWork 新增 Profiles 与 Dashboards（公开预览），CoCo 与 CoWork 引入可在后台自主推进目标的 Bots。此外宣布扩大与 Oracle 合作，平台将作为第一方服务登陆 Oracle 云基础设施。公司援引 MIT Technology Review 调研称 55% 的高管将智能体洞察质量差归因于业务语境缺失。
为什么对数据平台重要： 业务本体把语义层的地位从报表辅助抬升为智能体回答的唯一准绳，与 Palantir 的本体路线正面相撞；网关层把智能体当作「员工」来鉴权、计量与限速，意味着平台开始为机器调用方重建访问与成本模型；OCI 第一方合作延续多云被动防御策略，Oracle 系数据资产被直接接入路径。（[补录 11-03]，属上期窗口内发布会，上期未及收录）

微软把 OneLake 定位为智能体优先数据工程的文件系统，托管 MCP 与端点发现接口亮相

来源： 微软技术日报（转述 11 月 4 日 Fabric 官方博客，作者 Tom Peplow）
摘要： 11 月 4 日 Fabric 官方博客将 OneLake 类比为智能体时代的文件系统：引擎是程序、提示词是终端。配套发布两项预览能力：一是托管版 MCP 服务器，智能体无需在每台机器维护本地 MCP 进程，本地选项保留，Fabric Core 的 MCP 服务器同时新增快捷方式管理与安全规则管理两组工具；二是端点发现接口，一次 GET 调用即返回某工作区条目下各引擎（如 SQL 分析端点、OneLake 引擎）的托管 MCP 服务器、技能与直连端点，直连端点类型覆盖 DFS、Blob、ABFS、Delta、Unity Catalog 与 Iceberg。文档明确该接口只返回连接元数据，不执行查询、不授予权限，能力标签不能当授权凭证。
为什么对数据平台重要： 端点发现把「哪种表用哪个引擎」的维护责任从客户端清单转为服务自描述，是数据平台接口向智能体敞开的基础设施动作；托管 MCP 与上期 Azure 容器应用网关的 MCP 网关形成网关层与数据层两级治理，微软在智能体接入路径上的卡位最完整。

谷歌云更新智能体数据云：AlloyDB Express 扩大预览、面向智能体的 Postgres 与 BigQuery 图分析转正

来源： AlloyDB 官方文档（AlloyDB Express 概览）
摘要： 谷歌云围绕智能体数据云公布一组更新：AlloyDB Express 扩大预览，实例约两秒即可完成配置并接受连接、闲置时算力缩容至零，定位智能体快速原型与开发测试；同时推出面向智能体交互场景的 AlloyDB PostgreSQL 配置，以隔离的工作负载环境支撑每秒三百万次查询；BigQuery Graph 正式商用，把拍字节级图分析带入关系表且无需 ETL。AlloyDB 还新增对外部 Iceberg 表的标准 PostgreSQL 查询集成，把实时事务数据与湖仓记录连在同一条查询路径上。
对数据平台的影响： 两秒级配置加缩容到零，本质是为高频、短生命周期智能体会话重画数据库的成本曲线；事务库直查 Iceberg 表进一步模糊湖与库边界，与 Snowflake、Databricks 的湖仓路线在智能体负载上会师。

阿里云 EMR Serverless StarRocks 11 月版本：对象表引入多模态 AI 与文件处理

来源： 阿里云 EMR Serverless StarRocks 核心发布记录
摘要： 阿里云 11 月 4 日发布 EMR Serverless StarRocks 3.5.16 系列：Object Table 新增多模态 AI 与 FILE 处理能力，支持文档解析、音视频转写与理解，并提供 AI 输入预算控制与统一授权；文件访问升级为 OSS STS V4 签名并增加运行节点能力检查；基于 Tantivy 的原生全文检索增强复合索引、短语匹配与 BM25 相关性评分；Paimon 侧优化全文检索下推、修复数据更新可见性问题并改善写入效率。
对数据平台的影响： 查询引擎内直接消费非结构化数据并内置 AI 预算与授权，是国内厂商把「湖仓里的多模态数据直接喂给模型」产品化的具体一步；AI 输入预算控制把模型调用成本纳入引擎治理，与海外厂商的成本治理方向一致。

【投融资】智能体数据安全公司 Sentra 完成 1.5 亿美元 C 轮，Capital One Ventures 领投

来源： PR Newswire 官方新闻稿
核心数据： C 轮 1.5 亿美元，Capital One Ventures 领投并获董事会席位，Bessemer、Zeev、Standard Investments、Munich Re Ventures、Key1 跟投；累计融资超 2.6 亿美元；公司称过去一年增速超 300%。
摘要： Sentra 于 11 月 4 日宣布融资，主打「智能体数据安全」：在数据静态存放处完成分类，绘制人员、服务账号与 AI 智能体对敏感数据的可达映射（含继承权限），对非人类身份执行最小权限，异常访问自动回收，全部分析留在客户环境内。公司将智能体称为「企业数据最繁忙的消费者」，并称多数机构尚无治理机制约束智能体可达范围。
对数据平台的影响： 智能体成为数据平台的新调用方后，访问治理从库表权限扩展到「哪个智能体能触达哪类数据」，数据安全预算开始随智能体数量重新定价；Capital One 这类金融机构领投，说明受监管行业是该品类最先付费的场景。
