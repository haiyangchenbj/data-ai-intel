Top Signals

dbt Core 2.0 正式 GA：Rust 重写完成，分析工程工具链进入代际切换

来源： dbt-core v2.0.0 Release
摘要： dbt Core 2.0.0 正式 GA，标志 Rust 重写从候选版转入稳定版，带来全新执行引擎与扩展的平台集成能力。
为什么对数据平台重要： dbt 是分析工程的事实标准工具，其底层引擎重写改变性能上限与扩展方式，直接关系到大量依赖 dbt 建模的数据团队的升级节奏与迁移评估。

Databricks 为 Spark 有状态流查询推出无损分区重配（Public Preview）

来源： Announcing On-Demand State Repartitioning
摘要： Spark Structured Streaming 有状态流查询新增 On-Demand State Repartitioning（Public Preview），可在不丢失 checkpoint 状态的前提下调整分区数，适用于 Databricks Runtime 18 LTS 及以上、RocksDB 状态存储。Coveo 案例显示 S3 API 调用成本下降约 40%。
为什么对数据平台重要： 有状态流查询的分区数长期是"启动时一次性决定、改动需重建状态"的架构短板，无损分区重配让流作业可随负载弹性伸缩而不中断，降低长期运行流作业的成本与运维压力。

Product & Tech

腾讯云 TCHouse-C 上线存算分离弹性版（公测）

来源： 腾讯云 TCHouse-C 产品动态
摘要： TCHouse-C 上线全新弹性版（公测），采用存储计算分离架构，计算节点无状态、数据持久化到共享托管存储，支持以计算资源组为维度独立弹性伸缩，并默认开启冷热分层。
对数据平台的影响： ClickHouse 托管服务走向存算分离，面向潮汐负载与海量数据场景提供更低的存储成本与更快的弹性扩缩，对齐云原生湖仓的架构演进方向。

Snowflake AI_SUMMARIZE 支持多模态主题摘要（Public Preview）

来源： Snowflake Release Notes
摘要： Snowflake Cortex AI_SUMMARIZE 现支持多模态内容（Public Preview），可用单一 SQL 函数对文本、图片、图表、报告、合同等内容自动提取主题、事实与关系，无需自定义 prompt、模型选型或文档处理管线。
对数据平台的影响： 多模态内容摘要下沉为 SQL 原生能力，降低非结构化数据处理的工程门槛，强化「数据与 AI 在同一平台内」的产品主张，影响企业摘要类分析管线的技术选型。

Apache Doris 披露授权绕过漏洞（CVE-2026-68570）

来源： NVD CVE-2026-68570
摘要： Apache Doris 披露 Incorrect Authorization 漏洞（CVE-2026-68570，CWE-863），已认证用户可绕过权限检查读取未授权数据。影响 2.0.0–2.1.*、3.0.0–3.0.*、4.0.0 低于 4.0.8、4.1.0 低于 4.1.4，建议升级至 4.0.8 或 4.1.4。
对数据平台的影响： Doris 是主流开源 OLAP 分析引擎，授权绕过直接影响数据安全边界，使用方需尽快升级并核查权限基线，是数据平台治理维度的一次高优先级处置。
