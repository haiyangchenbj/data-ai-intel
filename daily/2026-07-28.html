MCP 2026-07-28 规范正式发布：Agent 与数据平台交互接口完成生产级转型

来源： MCP 2026-07-28 Spec Release Notes
摘要： Model Context Protocol（MCP）2026-07-28 版本于今日正式发布，这是协议自 2025 年 11 月移交 Agentic AI Foundation（Linux Foundation 下设）后的首个完整规范周期，也是协议史上规模最大的修订。核心变化包括：取消会话绑定实现无状态核心架构、新增统一能力发现与治理语义、标准化全链路追踪（W3C Trace Context）、强化 OAuth/OIDC 授权体系、引入 MCP Apps 交互式界面，以及首个正式弃用策略。
为什么对数据平台重要： MCP 是 AI Agent 调用数据平台工具（元数据查询、指标检索、治理化查询、数据新鲜度检查等）的主流标准接口。新规范的三项变化直接重塑数据平台的 Agent 接入架构：(1) 无状态核心使数据工具服务器可水平扩展，不再被会话绑定锁死在单实例；(2) 能力治理语义让平台侧可以限流、审计和缓存 Agent 的工具调用——这正是湖仓治理在 Agent 时代的落地形态；(3) 全链路追踪要求每次调用附带结构化来源信息，使 Agent 的数据操作可审计、可回溯，回应企业在 AI 规模化部署中的合规刚需。

腾讯云 TDSQL-C MySQL 版架构 2.0 正式商业化

来源： 腾讯云公告
摘要： 腾讯云公告，TDSQL-C MySQL 版产品架构 2.0 结束公测，自 2026 年 7 月 27 日起正式商业化计费。计费分为计算资源和存储资源两项，计算价格与架构 1.0 相同，存储价格低于架构 1.0。
对数据平台的影响： 架构 2.0 商业化标志着腾讯云关系型数据库产品线完成架构代际切换，存储成本降低有利于客户在云原生数据库上承载更大规模数据工作负载。存储价格下探也进一步压缩了传统自建 MySQL 的成本优势空间。
