阿里云正式推出 AI 原生大数据服务 ADA，以多智能体编排重组平台操作面

来源： 阿里云大数据AI技术：AI 原生大数据服务 ADA 正式发布
摘要： 阿里云 11 月 3 日正式推出 AI 原生大数据服务 ADA，定位以智能体为核心的数据生产力平台。AdaWork 主智能体统一理解意图、拆解任务并调度 MaxCompute、Hologres、Flink、EMR、DataWorks 等引擎的内置 Agent，内置数据分析师、语义建模、数据工程、数据治理与智能运维等专业角色协同；语义模型、指标口径与分析经验沉淀为统一知识中枢，所有结论附引用溯源；官方称其 Agent 直接内嵌在数据系统内部，可实时感知运行状态并自主排查诊断，权限继承 RAM 体系并全程审计。产品页与帮助文档同步上线（aliyun.com/product/ada）。
为什么对数据平台重要： 厂商第一次把大数据平台的操作面整体重组为多智能体协作结构：入口从控制台与 SQL 变成对话与任务编排，语义层从配套能力变成智能体回答的统一口径来源，权限与审计直接复用平台既有体系。数据平台的竞争位置从提供引擎转向提供 Agent 的调度与治理框架，语义层和口径管理成为新的必争层；同类的智能体工作台（DataWorks Data Agent、各引擎助手）从分散功能收敛为统一编排入口，跨引擎任务交付成为新的验收标准。

Snowflake Cortex AI Gateway 推理、可观测与成本管理正式 GA，兑现版本窗口预告

来源： Snowflake 服务器版本说明与功能更新（2026-11-03 两条）
摘要： Snowflake 官方功能更新 11 月 3 日发布两项 GA：Cortex AI Gateway 的推理、可观测性与成本管理正式可用，Google Gemini 4 Argon 模型同日 GA；另有 CoCo for Excel 与 Google Sheets 进入 Preview。上期 E1【跟踪】的 10.40 版本窗口开始兑现：11 月 3 日出现的能力以功能更新条目形式落地，10.40 行为变更包本身仍列在 Upcoming（见本期 E3）。
为什么对数据平台重要： 网关层 GA 意味着模型调用正式成为数据平台内的一等资源：用量、延迟与成本进入与计算资源同级的管控界面，多模型统一走平台网关，成本归因从账单后置变成调用前策略。数据平台的 AI 能力竞争进入「运营层」：谁先把模型调用做成可预算、可审计、可配额的资源，谁就能承接企业级 Agent 工作负载；表格端（Excel/Google Sheets）进入 Preview 则把分析入口延伸到电子表格人群。

国家数据局「十五五」数据要素部署：顶层文件在制定，AI 用数安全探索新型治理

来源： 国家数据局政策和规划司负责人在国家发展改革委奋进「十五五」系列新闻发布会上答记者问
摘要： 11 月 3 日国家发展改革委举行奋进「十五五」系列首场发布会，国家数据局政策和规划司司长栾婕介绍五方面部署：健全数据产权、流通利用、收益分配、安全治理等基础制度，数据产权登记服务系统已上线，登记凭证将在数据交易、资产入表、司法裁判中发挥可信证明作用；加快制定全国一体化数据市场顶层文件，完善流通交易规则和标准，鼓励市场化数据定价；谋划新一轮「数据要素×」三年行动；针对人工智能用数的数据安全问题探索新型治理机制，加快研究数据合规流通、匿名化等指引；建设数据跨境流动服务基础设施。
为什么对数据平台重要： 「十五五」数据部署从地方规划（北京、山东规划已在此前两期收录）上升到国家层面的顶层文件节奏，数据要素市场规则、定价机制与收益分配将进入密集出台期。AI 用数被单独点名为治理对象，合规流通与匿名化指引直接影响数据平台向模型训练与智能体供给数据的合规设计；登记凭证的可信证明地位则把数据资产入表的口径进一步压实。

Azure 容器应用网关公测 MCP 网关：多 MCP 服务器聚合与网关层安全收敛

来源： Azure Updates：Public Preview - MCP gateway for Application Gateway for Containers
摘要： 微软 11 月 3 日公测 Application Gateway for Containers 的 MCP 网关：新增 MCPRoute 自定义资源，支持多个 MCP 服务器聚合在单一受管端点之后，网关层集中 TLS、JWT 校验、WAF 防护、后端健康检查与路由策略；聚合部署下自动合并工具、资源与提示发现响应，并对能力名做命名空间化避免冲突；支持会话亲和以承接维护内存会话状态的 MCP 服务器。
对数据平台的影响： 智能体成为数据平台调用方之后，MCP 流量治理从各应用自建上移到网关层，与 API 网关治理 HTTP 流量同构。企业数据平台的 MCP 接入可以复用同一套边界控制（认证、WAF、审计、健康检查），智能体接入层开始成为基础设施标配组件；多服务器聚合与能力名命名空间化直接回应了企业内部 MCP 服务器数量膨胀后的治理问题。

阿里云 Dataphin 发布 V6.4：网络权限、非结构化架构升级与自然语言消费渠道

摩根士丹利：三大云三季度营收增速再加快，竞争延伸到数据分析与企业 AI 应用层

来源： 新浪财经：大摩研报——AI 热潮带动云计算需求全面加速（2026-11-03）
核心观点： 摩根士丹利 11 月 3 日研报：三大云服务商三季度合计营收约 1099 亿美元、同比增长 55.7%（二季度为 47.9%）；AWS 固定汇率同比 +39%，连续六个季度加速；Azure 同比 +48%；Google Cloud 同比约 +103%，剔除 TPU 系统销售后核心业务约 +71%。亚马逊称 AI 推理业务已占其 AI 收入一半以上，AgentCore 本季度部署的智能体数量为此前三季度合计的两倍；微软 Foundry 平台收入同比增长超两倍，Agent365 登记智能体超 5000 万个、环比增逾 30%；Alphabet 称 BigQuery 查询速度同比提升超 40%、查询处理成本下降超 50%。大摩判断：云竞争正从底层计算资源延伸至数据分析和企业 AI 应用层；智能体若能直接查询企业数据平台，反而可能进一步增加平台使用量。
映射到数据平台的判断： 云巨头财报口径首次把智能体数量与推理收入占比作为增长叙事的主角，数据平台被夹在两条曲线之间：上游算力被模型研发优先占用，下游分析层被云巨头自营能力挤压（亚马逊把 DuckDB 定位为存储分析的通用查询语言、BigQuery 提速降价）。采购逻辑需要同时评估算力供给的优先级风险与平台自营分析替代独立数据平台的风险；而智能体带来的查询增量是数据平台厂商在财报季可以讲的新故事。

皮查伊：算力优先给前沿模型研发，云业务让渡短期收入

来源： InfoQ：谷歌宁愿少卖云算力，也要先把算力留给 Gemini（2026-11-03 编译 Big Technology Podcast 访谈）
核心观点： 谷歌 CEO 皮查伊在 Big Technology Podcast 访谈中披露：Gemini 4 Argon 上线后前 72 小时 token 消耗接近 25 万亿，约为 Gemini 3.0 同期的三倍；为保障前沿模型研发，谷歌已将算力优先分配给 AI 研究团队，云业务因此放弃部分短期收入。他同时表示谷歌内部不再以「AI 写代码比例」为核心指标，Gemini 4 Argon 发布后四周内代码变更提交量增加约 30%、回滚次数减少约三分之一，转向实效性工程指标。
映射到数据平台的判断： 算力在前沿模型研发与对外云收入之间出现了显式的内部定价与让渡次序：自有模型优先，客户负载靠后。这给企业数据平台的算力与配额规划提出新的评估项：厂商自用需求（尤其是模型迭代冲刺期）会挤占对外供给，容量承诺、价格稳定性与降级条款应写进采购谈判；「厂商把算力留给自家模型」从猜测变成了厂商自述。
