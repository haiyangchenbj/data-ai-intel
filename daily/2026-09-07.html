NVIDIA 官宣 129.3 亿美元收购 Hugging Face [补录 09-03]

来源： InfoQ 中文（NVIDIA 官方博客编译）
摘要： NVIDIA 于 9/3 官宣（9/2 签署最终协议）以 129.3 亿美元收购全球最大开源模型与数据集平台 Hugging Face，其中约 119 亿美元现金、最高 10 亿美元员工股权保留，预计 2027 上半年交割；平台托管超 300 万模型、50 万数据集、1800 万开发者。NVIDIA 承诺维持平台中立开放与多加速器兼容，但美欧反垄断审查是最大变数。
为什么对数据平台重要： 这是算力巨头向「模型发现—分发—部署」入口与数据集供应链上游延伸的标志性事件，把开发者默认依赖的开源模型仓库纳入芯片生态，直接改写 AI 数据供应链与开放生态的话语权格局，也是继此前传闻后的正式落地。

Google Cloud 发布数据库运维 AI 智能体

来源： InfoQ（Google Cloud 官方博客）
摘要： Google Cloud 推出 Onboarding Agent（自然语言选型）与 Observability Agent（多源遥测关联根因分析）两款数据库运维智能体，深度集成 Gemini Cloud Assist，覆盖 Cloud SQL、Spanner、AlloyDB、Bigtable、Firestore 与 Memorystore；相关能力可通过 MCP 服务器接入现有工作流。
为什么对数据平台重要： 数据库「选型—部署—诊断—调优」全生命周期开始由智能体接管，标志云数据库运维从工具化走向 Agent 化，治理能力与工程效率成为云数据平台新的竞争维度。

阿里云 PolarDB-X 1.0 发布退市公告

来源： 阿里云帮助中心
摘要： 阿里云宣布云原生数据库 PolarDB-X 1.0（原 DRDS）启动退市，分三阶段推进：2026/10/15 停止新购、2027/4/15 停止续费与变配、2027/10/15 全面停止服务；官方建议迁移至 PolarDB-X 2.0 企业版，并提供可视化评估迁移工具覆盖结构迁移、全量与增量同步、校验与回滚。
对数据平台的影响： 云数据库进入存量代际更替期，上一代分布式架构产品被明确退役，用户被迫向新一代云原生分布式架构迁移；对采购方是明确的升级窗口信号，对厂商则是产品线收敛与资源聚焦的治理动作。

Omdia：OceanBase 位居亚太分布式数据库市场第一

来源： 北京商报（Omdia《2026 年亚洲及大洋洲分布式数据库市场研究》）
核心观点： 按 2025 年收入计算，OceanBase 以 15.5% 份额位居亚太分布式数据库市场第一，领先腾讯云 TDSQL、Google Cloud Spanner、华为云 GaussDB 与阿里云 PolarDB-X。
映射到数据平台的判断： 国产数据库厂商首次在第三方区域市场排名中超越海外云巨头，标志「替代 Oracle」叙事之后，海外拓局成为国产数据库的第二增长曲线；需注意该排名为 Omdia 口径并经厂商 PR 放大，市场界定与收入口径应交叉验证。
