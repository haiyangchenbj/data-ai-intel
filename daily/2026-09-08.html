AWS Redshift 支持 Apache Iceberg v3

来源： AWS 官方周报（转载）
摘要： AWS 9/7 周报确认，Amazon Redshift 现支持读写 Apache Iceberg v3 表，新增默认列值、行谱系（row lineage）与删除向量（deletion vectors）支持，覆盖 Graviton 预置集群与 Redshift Serverless。数据湖分析可直接读写 v3 格式 Iceberg 表，与湖上其他引擎共享同一套开放表格式。
为什么对数据平台重要： 开放表格式正从 v2 向 v3 演进，删除向量与行谱系是 v3 的核心增量；主流云数仓对 v3 的跟进，标志湖仓一体的开放表格式进入新一轮标准化，进一步降低数据湖与数仓之间的格式壁垒。

腾讯云 PostgreSQL 内核支持相关子查询并行执行

来源： 腾讯云数据库 TencentDB（腾讯新闻转载）
摘要： 腾讯云数据库 PostgreSQL 内核支持相关子查询（SubPlan）并行执行，开启 tencentdb_enable_subplan_parallel 参数后，含相关子查询的 SQL 也能多核并行。基于 PostgreSQL 18 内核，在 32 核测试机上同类 SQL 获得 4.2 倍加速。
为什么对数据平台重要： 相关子查询是业务 SQL 常见写法，原生 PostgreSQL 对其"一刀切"禁止并行是长期性能短板；在内核层绕过该限制，标志国产云数据库进入内核级工程能力比拼，而非停留在兼容性增强。
